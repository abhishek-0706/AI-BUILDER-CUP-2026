RetailIQ connects sensing, execution and empowerment in CPG retail. Field reps capture shelf evidence, confirm inventory gaps, prepare source-linked buyer conversations and save records for manager review. Gemini supports audits, rehearsal and discovery; code computes scores and stock-aware quantities using demand, inbound stock, case sizes and shelf life. Own-brand compliance is separate from competitor benchmarking. Buyers retain order approval. Managers inspect evidence; shoppers compare catalogue options by need, price and nutrition. The public prototype uses Firebase Spark with billing disabled, a no-key recorded scenario and optional unbilled AI Studio access. The implemented backend reference uses Cloud Run, Vertex AI, BigQuery/BQML, Firestore and private Cloud Storage. Commercial data is synthetic. Reports distinguish local regressions from historical cloud checks; time savings and uplift remain pilot hypotheses.
