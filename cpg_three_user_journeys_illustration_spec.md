# CPG / FMCG AI — 3 User Journey Character & Illustration Specification

## Purpose

Enhance the existing 3-card landing UI with three clear user-journey illustrations and role-based characters.

The goal is **not to redesign the UI**. The goal is to make each journey instantly understandable through a premium visual story while preserving the current product renders, typography, colors, CTA hierarchy, spacing, and card structure.

Reference UI image:
`/mnt/data/image(20261007-035227).png`

---

# 1. Current User Journeys

The page has three primary journeys:

### Journey 1 — Field Sales Rep
**Role:** FIELD SALES REP

**Headline:**  
I am visiting stores

**Current description:**  
Plan the day, pitch the buyer, audit the shelf and place the order.

**Current capability cues:**
- Visit brief and AI pitch for each buyer
- Shelf photo audit against the planogram
- Suggested order and visit debrief

**User journey:**

`PLAN → VISIT → AUDIT → ORDER`

---

### Journey 2 — Sales Manager
**Role:** SALES MANAGER

**Headline:**  
I lead a sales team

**Current description:**  
See coverage, sell-through and stock risk across the territory, and coach your reps.

**Current capability cues:**
- Territory sales numbers and category performance
- Stock-out and expiry alerts
- AI coaching notes per rep

**User journey:**

`MONITOR → IDENTIFY RISK → COACH → IMPROVE`

---

### Journey 3 — Brand & Category / Shopper
**Role:** BRAND AND CATEGORY

**Headline:**  
I want to know the shopper

**Current description:**  
Understand what shoppers ask for and what goes in their basket, in their own words.

**Current capability cues:**
- Shopper segments and missions
- Conversational shopping assistant
- Basket and recommendation insight

**User journey:**

`ASK → DISCOVER → COMPARE → BUY`

# 2. Recommended Visual Direction

## Strong recommendation

Use **premium semi-3D editorial human illustrations**.

The characters should feel like they belong to the same visual system as the existing CPG/FMCG product renders.

### Desired characteristics

- Premium
- Modern
- Enterprise-grade
- Human
- Approachable
- Slightly dimensional / semi-3D
- Realistic human proportions
- Soft studio lighting
- Soft shadows
- Clean rounded shapes
- Subtle facial features
- Sophisticated rather than playful
- Modern AI-product aesthetic
- CPG / retail context
- Transparent or very light background

### Avoid

- Generic stock-photo people
- Cartoonish characters
- Children's-app style
- Anime
- Flat generic corporate vectors
- Overly realistic photographs
- Exaggerated facial expressions
- Highly detailed scenes
- Large UI panels embedded in the artwork
- Excessive floating widgets
- Characters that look like sales mascots

---

# 3. Character System

The three characters should clearly look like they belong to the **same illustration family**.

Keep consistent:

- Head/body proportions
- Facial style
- Lighting direction
- Shadow softness
- Rendering quality
- Clothing treatment
- Line/detail level
- Material quality
- Overall scale

However, each character should have a distinctive silhouette and role.

## Role differentiation

### Field Sales Rep
Visual identifiers:
- Smart-casual polo or sales shirt
- Tablet in one hand
- Small sales bag/backpack
- Store environment
- Shelf/product interaction

Core visual message:

**"I am in the field and getting the store visit done."**

### Sales Manager
Visual identifiers:
- Smart business-casual outfit
- Tablet/laptop
- Leadership posture
- 2–3 subtle rep/team figures
- Territory / performance cues

Core visual message:

**"I see what is happening across my team and take action."**

### Shopper
Visual identifiers:
- Contemporary casual clothing
- Shopping basket and/or phone
- Examining products
- Grocery/convenience environment
- Natural curiosity

Core visual message:

**"I understand the shopper's intent and help them choose."**

# 4. Journey 1 — Field Sales Rep Illustration

## Character

Create a young-to-mid-career FMCG field sales professional.

Appearance:
- Modern smart-casual polo or sales shirt
- Clean professional appearance
- Tablet in hand
- Small sales bag/backpack
- Confident and approachable posture
- Natural, focused expression

Do not invent a company logo.

## Scene

The character is inside a grocery/convenience store.

Include:
- A product shelf
- Protein/snack products
- Subtle store environment
- Optional store buyer in the background

Do not make the background visually dense.

## Storytelling

The scene should communicate:

`PLAN → VISIT → AUDIT → ORDER`

Possible subtle contextual cues:
- Visit Brief
- Shelf Audit
- Suggested Order

These should be tiny visual hints, not prominent dashboard cards.

## Composition

Recommended composition:

`Character → Tablet → Shelf / Products`

Place the character toward the upper/right part of Card 1, without covering:
- Heading
- Body text
- Product renders
- CTA

The character should complement the existing product imagery rather than replace it.

## Card 1

**Sales rep + tablet + shelf/product**

## Card 2

**Manager + performance insight + team**

The character should visually connect the AI dashboard to team management.

## Card 3

**Shopper + products + recommendation**

# 10. Responsive Behavior

## Desktop

- Keep 3-column card layout
- Show complete character illustration
- Keep product renders visible
- Maintain current card proportions

## Tablet

- Slightly reduce character scale
- Maintain text readability
- Reduce decorative UI cues if necessary

## Mobile

Stack the three journeys vertically.

Preferred order:

1. Field Sales Rep
2. Sales Manager
3. Brand & Category

Character should remain visible above/near the product visual.

Never allow:
- Illustration to cover CTA
- Character to cover text
- Floating elements to cause horizontal overflow

---

# 11. Animation Recommendation

Use animation sparingly.

Recommended:
- Small fade + translate on card hover
- Character moves 2–4 px upward
- Very subtle floating motion for AI cue
- Product render remains mostly stable

Avoid:
- Large character movements
- Bouncing
- Continuous distracting animation
- Fast transitions
- Excessive parallax

Animation should communicate that this is an AI-powered product without making the UI feel like a marketing gimmick.

# 16. Code Implementation Guidance

Before changing anything:

1. Inspect the existing project structure.
2. Identify the component for the three cards.
3. Identify the current design tokens.
4. Identify existing product-image assets.
5. Inspect current responsive breakpoints.
6. Reuse the existing styling system.

Then add the character layer.

Do not rebuild the entire page.

Do not unnecessarily introduce a new component library.

Prefer reusable data-driven configuration.

Example conceptual structure:

```js
const journeys = [
```

# 17. Important Design Principle

The illustrations are not decoration.

Each image should answer:

**"Who am I, what am I doing, and why does this AI experience matter to me?"**

Within roughly 1–2 seconds, the user should understand:

### Card 1
"I am a rep going into a store."

### Card 2
"I manage reps and need visibility and coaching."

### Card 3
"I care about what shoppers want and why they buy."

---

# 18. What I Would NOT Change

Do not change:

- Existing card count
- Existing three-column structure
- Existing CTA copy
- Existing primary headings
- Product packaging renders
- Existing brand colors
- Existing typography unless required for spacing
- Existing overall visual style
- Existing interaction behavior

The enhancement should feel like **the next polished version of the same product**, not a redesign.

# 20. Final Recommendation

The strongest implementation is:

**Premium semi-3D human character + existing product render + one subtle contextual AI cue + clear journey metaphor.**

Do not turn the cards into miniature dashboards.

Keep the experience visually simple:

### Field Rep
**Person in store + tablet + shelf**

### Sales Manager
**Manager + team + performance**

### Shopper
**Shopper + products + recommendation**

That balance will make the UI feel like a **premium AI-powered CPG/FMCG platform**, while the three characters give the user an immediate emotional and functional connection to each journey.
